# Definition of Done

## Context

- [ ] Git 기준점과 관련 Diff 검토
- [ ] Project Map 검토
- [ ] 대상 Feature Current 검토
- [ ] Related Files 및 Shared Dependencies 검토
- [ ] Stack Readiness 및 Capability Decision 검토
- [ ] 필요한 1차 Source Knowledge 검증

## 실행

- [ ] Feature 단위 작업에 Active Worklog 존재
- [ ] 5단계 Gate Header 전체 완료
- [ ] Expected Files 및 인정된 예상 밖 File 기록
- [ ] Todo 진행과 Micro-Verify 최신
- [ ] 추출 Source Evidence 저장

## Validation Layer

- [ ] Artifact / Compile
- [ ] Unit / Integration
- [ ] Rendered Output
- [ ] Runtime Behavior / E2E
- [ ] Accessibility / Color
- [ ] 필수 Visual Block 존재 및 비어 있지 않음
- [ ] Git Scope
- [ ] State Model 및 Document 동기화

해당하지 않는 Layer는 명시합니다. 실행하지 않은 필수 Layer는 PASS가 아니라 PENDING입니다.

## State 및 Version Control

- [ ] Feature Current에 `code-verified` 기록
- [ ] Append-only Feature History Entry 추가
- [ ] 가능한 경우 Commit과 PR 기록
- [ ] Project Map 갱신
- [ ] Shared File Reverse Index 갱신
- [ ] Cross-feature Decision 변경 시 Architecture State 갱신
- [ ] Active Worklog 종료 또는 Archive
- [ ] 최종 Git Diff 검토
- [ ] 무관한 변경 없음
