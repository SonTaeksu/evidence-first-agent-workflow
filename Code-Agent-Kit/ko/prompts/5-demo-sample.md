# 5 — 격리된 Demo 작성

1. 모든 Demo Artifact를 `demos/<name>/` 아래에 둡니다.
2. Demo가 Integration Boundary를 명시적으로 검사하지 않는 한 Production Code를 수정하지 않습니다.
3. 구현 전에 Source Asset을 보존하고 Image 또는 SPA Evidence를 생성합니다.
4. Code 작성 전에 예상 UI Block을 전부 나열합니다.
5. 빈 Placeholder Box를 완료로 인정하지 않습니다.
6. 목적, 실행 명령, Validation을 Demo README에 기록합니다.
7. 유용한 결과는 조용히 복사하지 않고 정상 New Feature Prompt로 승격합니다.
