# Roo Code 및 Zoo Code 프로젝트 설정

Roo Code와 Zoo Code는 모두 프로젝트의 `.roo/mcp.json`에서 MCP 서버 설정을 읽을 수 있습니다.

프로젝트 규칙은 `.roo/rules/10-evidence-first.md`에 있습니다.

설정된 MCP:

- Microsoft Learn MCP
- Context7 MCP

공개 알파 단계에서는 MCP 도구 자동 승인을 비워 두었습니다. 도구 호출을 확인한 뒤 승인하세요.

저장소를 연 뒤:

1. MCP Servers를 활성화합니다.
2. MCP 설정 화면을 엽니다.
3. Project MCP 파일이 감지됐는지 확인합니다.
4. `microsoft-learn`, `context7` 연결을 확인합니다.
5. Root의 `AGENTS.md`를 읽습니다.
