# Roo Code · Zoo Code 어댑터 — 구속 규칙

Roo Code·Zoo Code가 `.roo/rules/`의 규칙을 자동 로드합니다. 완전하고 구속력 있는 규칙은 프로젝트 루트의 `AGENTS.md`입니다 — 읽고 따르세요. 이 어댑터가 대체하지 않습니다. 항상 유효한 비협상 규칙:

- 정직이 완료보다 우선: 자기 실수를 보고하고, 불확실하면 추측 대신 멈추며, "완료"는 검증 통과한 것만.
- 파일을 바꾸는 모든 작업은 `prompts/GATE.md`의 5단계 Gate를 거치고 `prompts/0-sync-and-orient.md`에서 시작.
- 커밋 게이트가 워크로그·Gate 섹션·상태 동기화 없는 소스 변경을 차단(`docs/core/enforcement-matrix.md`). 절차 생략은 잡히며 시간 절약이 아님.

`prompts/`, 활성 기능 `current.md`/워크로그, 가장 가까운 Stack `SKILL.md`를 사용.
