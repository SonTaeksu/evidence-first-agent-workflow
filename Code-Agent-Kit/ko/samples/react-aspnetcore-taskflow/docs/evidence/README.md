# Validation 증거

자동 생성된 증거는 `generated/` 아래에 저장합니다.

각 기록에는 다음이 포함돼야 합니다.

- 실행 명령
- Working Directory
- 시작 및 종료 시각
- 종료 코드
- 캡처한 출력
- PASS 또는 FAIL

실패한 명령을 사람이 임의로 PASS로 바꾸면 안 됩니다.

## 자동 생성 로그 번역 정책

`generated/*.md`는 실제 명령 출력이 포함된 원본 증거입니다. 증거 무결성을 위해 원문 출력을 번역하거나 수정하지 않습니다.

한국어 대응 문서인 `*.md`에는 결과 요약과 원본 증거 링크만 기록합니다.
