# Stack 전용 Agent Rule

Root `AGENTS.md`를 확장합니다.

- Stack 의존 구현 전에 `STACK-READINESS.json`을 읽습니다.
- Blocking Capability가 `unknown`이면 해당 Pattern 사용을 금지합니다.
- 선택 Reference Routing은 `SKILL.md`를 사용합니다.
- 기억 대신 검증 Fact, Provenance, Skeleton을 사용합니다.
- Stack Feature, Artifact, Communication, Validation Contract를 따릅니다.
- 선택한 모든 Capability를 Project Map과 Gate Analysis에 기록합니다.
