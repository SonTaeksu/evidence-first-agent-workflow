# Artifact Contract

| Artifact | 필수 형태 | Source 또는 Skeleton | Generated Ownership | Validation |
|---|---|---|---|---|
| | 대체물이 아닌 실제 Framework File | | human / tool / vendor | |

Rule:

- 설치 또는 확인된 Framework Version 사용
- Schema 민감 시 검증 Skeleton 복사
- 필요한 Framework Artifact를 무관한 HTML/Text Mock으로 대체하지 않기
- Ownership이 명확하지 않으면 Vendor Generated File 수정 금지
