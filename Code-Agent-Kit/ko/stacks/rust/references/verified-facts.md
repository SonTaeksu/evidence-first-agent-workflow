## 규칙

- 각 행에는 Source가 있어야 합니다. Source가 없으면 기억일 뿐이고, 기억은 누구의 Reference
  File에도 들어가지 않습니다.
- Version에 민감한 Fact는 어떤 Version에 대해 검증했는지를 밝힙니다.
- `references/pitfalls.md`는 기술 자체의 속성을 담고, 이 File은 *이 Project*에 관한 Fact를
  담습니다. 둘은 같지 않으며 합치지 않습니다.
