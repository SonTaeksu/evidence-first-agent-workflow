# 출처 라우팅

## ASP.NET Core 및 Microsoft 기술

다음 항목은 Microsoft Learn MCP를 사용합니다.

- ASP.NET Core API
- C#
- .NET Hosting과 Configuration
- Dependency Injection
- Logging
- Authentication과 Authorization
- Test API
- 영속성을 추가할 경우 Entity Framework Core

공식 문서를 조회할 수 있다면 모델 기억에만 의존하지 않습니다.

## React 및 JavaScript 라이브러리

Context7을 사용합니다.

고정 React Core 라이브러리:

```text
/facebook/react
```

Vite, Vitest, React Testing Library, Playwright 문서를 조회하기 전에 정확한 Library ID를 확인합니다.

## 우선순위

1. 현재 프로젝트 코드와 결정론적 Validation
2. Microsoft Learn 또는 공식 출처 기반 Context7 자료
3. 공식 저장소와 릴리스 노트
4. 모델 기억

문서의 버전과 샘플 버전이 충돌하면 중단하고 불일치를 보고합니다.
