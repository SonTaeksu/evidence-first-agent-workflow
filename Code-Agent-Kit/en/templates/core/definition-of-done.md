# Definition of Done

## Context

- [ ] Git baseline and relevant Diff reviewed
- [ ] Project Map reviewed
- [ ] target feature current reviewed
- [ ] Related Files and Shared Dependencies reviewed
- [ ] stack readiness and capability decisions reviewed
- [ ] primary-source knowledge verified where required

## Execution

- [ ] active worklog exists for feature-sized work
- [ ] all five Gate headings are complete
- [ ] Expected Files and acknowledged unexpected files are recorded
- [ ] Todo progress and Micro-Verify results are current
- [ ] extracted source evidence is stored

## Validation Layers

- [ ] Artifact / Compile
- [ ] Unit / Integration
- [ ] Rendered Output
- [ ] Runtime Behavior / E2E
- [ ] Accessibility / Color
- [ ] required visual blocks are present and non-empty
- [ ] Git scope
- [ ] state-model and document synchronization

Non-applicable layers are explicitly marked. Unexecuted required layers are PENDING, not PASS.

## State and Version Control

- [ ] feature current updated with `code-verified`
- [ ] append-only feature history entry added
- [ ] Commit and PR recorded when available
- [ ] Project Map updated
- [ ] Shared File Reverse Index updated
- [ ] architecture state updated when cross-feature decisions changed
- [ ] active worklog closed or archived
- [ ] final Git Diff reviewed
- [ ] no unrelated changes remain
