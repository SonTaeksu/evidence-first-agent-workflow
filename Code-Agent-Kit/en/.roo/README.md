# Roo Code and Zoo Code project configuration

Both Roo Code and Zoo Code can load project MCP servers from `.roo/mcp.json`.

This repository also provides `.roo/rules/10-evidence-first.md`.

Configured MCP servers:

- Microsoft Learn MCP
- Context7 MCP

Automatic tool approval is intentionally empty. Review MCP calls during the public alpha.

After opening the repository:

1. Enable MCP Servers.
2. Open the MCP settings view.
3. Confirm the project MCP file is detected.
4. Confirm `microsoft-learn` and `context7` are connected.
5. Read root `AGENTS.md`.
