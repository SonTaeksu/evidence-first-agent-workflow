# 1 — Analyze an Existing Project

Analyze one module or feature at a time.

1. Run `0-sync-and-orient.md`.
2. Identify entry points, contracts, shared dependencies, tests, and build commands.
3. Create or update Project Map.
4. Create current state and append-only history.
5. Record unknowns instead of inventing them.
6. Validate paths and commands.

Do not scan generated, vendor, dependency, or human-guide directories.
