# 6 — Debug and Fix

1. Run `0-sync-and-orient.md`.
2. Reproduce the exact failure.
3. Localize the failing layer and smallest relevant code path.
4. State the confirmed cause in one sentence with evidence.
5. Do not modify code before the cause is supported.
6. Apply the smallest correction.
7. Re-run the reproduction and regression checks.
8. Record cause, correction, commands, and evidence in the worklog and history.

Unknown API, version, property, or path values must remain marked as unknown.
