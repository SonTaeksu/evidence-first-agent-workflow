# 5 — Create an Isolated Demo

1. Put all demo artifacts under `demos/<name>/`.
2. Do not modify production code unless the demo explicitly tests an integration boundary.
3. Preserve source assets and create image or SPA evidence before implementation.
4. List all expected UI blocks before code.
5. Do not accept empty placeholder boxes as completion.
6. Add a demo README with purpose, run commands, and validation.
7. Promote useful work through the normal new-feature prompt rather than copying it silently.
