# 3 — Add a New Feature

1. Run `0-sync-and-orient.md`.
2. Confirm stack readiness and required user inputs.
3. Add the feature route to Project Map as planned state.
4. Create feature current, append-only history, and active worklog from templates.
5. Gather source evidence and primary-source provenance.
6. Use the mandatory five-stage Gate.
7. Synchronize current, history, Project Map, and Shared File Reverse Index.
8. Review final Git Diff.
9. Start the next feature in a fresh chat after DoD.
