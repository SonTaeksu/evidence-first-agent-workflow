# 0 — Sync and Orient

## Unfinished task

1. Read only the active worklog header and Resume Point to identify the feature.
2. Identify Git root, branch, status, and available base.
3. Fetch and compare `origin/main` when available.
4. Read Project Map.
5. Read the target feature current.
6. Read current's Related Files and Shared Dependencies.
7. Read the full worklog.
8. Resolve incoming overlap before resuming the recorded Gate stage.

## New work on an existing feature

1. Identify Git root, branch, status, and available base.
2. Fetch and compare `origin/main` when available.
3. Read Project Map.
4. Read the target feature current.
5. Read current's Related Files and Shared Dependencies.
6. Create a new worklog.
7. Continue with the situation prompt and `GATE.md`.

When no remote exists, use local `main` or `master` and record that remote synchronization was unavailable.
